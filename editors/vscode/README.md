# M0RX Language Support for VS Code

M0RX is a next-generation compiled programming language for the AI era.

## Features
- Syntax Highlighting
- Code Snippets
- M0RX Dark Theme
- Language Configuration
- Auto-closing brackets
- Comment toggling

## Snippets
| Prefix | Description |
|--------|-------------|
| fn | Function |
| class | Class |
| if | If statement |
| each | Each loop |
| let | Variable |
| try | Try-catch |
| server | API Server |
| ai | AI Chat |
| hello | Hello World |
