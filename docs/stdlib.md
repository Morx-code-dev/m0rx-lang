# M0RX Standard Library

## Core (m0rx.core)
Built-in functions: showln, show, ask, length, trim, upper, lower, absolute, root, power, append, remove, sort, reverse...

## Backend (m0rx.backend)
HTTP server, REST API, GraphQL, gRPC, WebSocket, Auth, ORM, Queue, Microservices, OpenAI/Anthropic/OpenRouter API

## UI (m0rx.ui)
2D/3D engine, animation, GUI components, game engine, mobile framework, desktop framework, events

## AI (m0rx.ai)
Local LLM, Cloud LLM, Tensor engine, Neural networks, RAG, Embeddings, Computer vision, NLP

## Voice (m0rx.voice)
TTS (20+ voices), STT (real-time), voice cloning, noise cancellation, 50+ languages

## Database (m0rx.db)
SQL (PostgreSQL, MySQL, SQLite), NoSQL (MongoDB), Vector DB (Pinecone, Qdrant), Query builder

## Security (m0rx.sec)
Hashing, AES/RSA encryption, JWT, OAuth2, TLS, input sanitization, rate limiting

## Network (m0rx.net)
TCP/UDP, HTTP client, DNS, WebSocket, proxy

## Async (m0rx.async)
Tasks, channels, event loop, coroutines, timers

## Cloud (m0rx.cloud)
AWS S3/Lambda/SQS/DynamoDB, GCP Storage/Firestore, Azure Blob/Queue, Cloudflare

## More Libraries
math, str, ds, algo, file, sys, serial, img, media, crypto, cache, log, config, web, date, pdf, chart, payments, i18n, geo, email, notify, queue, wasm, perf, compat, embed, robotics, test, cli
